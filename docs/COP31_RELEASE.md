# COP31 展示与每日编辑规则

更新日期：2026-10-27。

## 展示入口

- 主站：https://generationzprogrammer.github.io/climate-agent-news/
- 独立页：https://generationzprogrammer.github.io/climate-agent-news/cop31/
- 英文入口：https://generationzprogrammer.github.io/climate-agent-news/cop31/?lang=en

独立页由 `cop31_site.py` 从主站模板生成，共用自动更新的新闻、档案、PDF和统计。保留全球现场、今日情报、中国碳市场、新加坡、语料分析、情报问答、文本数据库，以及项目介绍与团队。不加载能源、企业、能源报告、地方专题、全国排放企业名录或科产融合资源。COP31页隐藏订阅入口，订阅代码、配置、既有名单和周报任务不变；主站其他功能不变。

## 中英文简报与问答

同一 `/cop31/` 页面内切换中英文，语言状态同步至URL参数，刷新后保持。所有每日简报下载入口随界面语言选择 `daily_brief.pdf` 或 `daily_brief_en.pdf`，两份文件由同一批约12条记录、同一新闻日期生成。下载链接带数据版本，避免沿用浏览器旧缓存。后续同日更新已恢复订阅入口，提供中英文邮件选择，并补齐Corpus图表分类标签和团队英文资料；维护细节以`SUBSCRIPTION_SETUP.md`的2026年10月27日更新为准。

日常中文编译同时输出忠实英文题名与50—100词概要。既有当日记录缺英文时，在导出步骤复用现有模型补充，每批2条、每次导出最多12条；结果按标题与中文概要指纹缓存在文章元数据，未变更内容不重复调用。英文生成失败时使用来源英文，确实缺失时明确说明，不混入中文冒充英文。新增英文输出会增加少量模型输出token，未增加模型供应商或Secrets。中文摘要质量门禁与每日06:30、18:30更新保持不变，GitHub调度和外部服务故障可能延迟发布，不能承诺每天严格满12条。

PDF采用宋体兼容中文字体、Times Roman英文与数字，按真实字宽换行，标题与正文保持同页，带页码；可点击原文链接集中于末尾。问答复用浏览器内证据检索，不是新增远程大模型服务；中文、英文提问均可识别当天、一周、比较、时间线及连续追问，回答随界面语言输出。问答的今日简报与页面、PDF共用同一批记录。订阅隐藏不影响其他操作。

## 每日编辑

目标12条，其中优先选择约4条COP相关议题：谈判与国家自主贡献、资金、损失损害、适应、国际碳市场、透明度、甲烷与公正转型。直接进入原有新闻、地图和PDF，不新建专题。词典标签仅表示编辑范围，不构成事实判断或官方议程认定。

仍只采用最新合格新闻的北京时间自然日，不用旧闻填满12条。中文标题、实质概要、发布时间、来源与链接质量门禁不变。地图只展示能定位的信息，每条一个主地点，全球性谈判不会人为归属某国，所以点数可能少于12。

原有10条发现查询保留，新增7条COP和区域短查询，俄罗斯同时用英文和俄文检索。各查询结果轮流取样、去重后进入150条处理上限，防止前几个宽泛查询占满名额。编译优先最新一天，常规定时最多32篇、代码发布最多48篇，每模型请求2篇。无新增模型供应商或Secrets。常规调用上限较原20篇提高60%，实际费用取决于现有API账户，不能承诺免费额度始终够用。更新仍在北京时间06:30、18:30，不新增高频轮询。

## 地域与国际组织

组织分类采用“太平洋岛国论坛（PIF）”。18个成员含澳大利亚、新西兰及16个岛国或地区。文本实际提及论坛才标注PIF，不把普通成员国报道误称为论坛行动；俄罗斯与太平洋岛国及地区分别以约5%滚动覆盖为软目标，岛国占比不包括澳大利亚、新西兰。

用过去6天每天平衡筛选样本和当天候选数估计缺口，在当天合格候选中各优先补充至多1条，再选择COP和其他重点新闻。这是编辑样本估计，不是已发布历史快照的精确占比。没有合格当日信息时不强凑，不改日期、不降低质量门槛，实际比例可能偏离5%。

## 测试与维护

`tests/test_cop31.py` 检查12条目标、COP优先、同日约束、岛国识别、PIF歧义排除、分查询轮流取样、最新日编译优先和独立页生成。既有摘要、去重、订阅与地图测试继续运行。每次Pages导出同步生成独立页；100000条档案上限不变，无历史记录删除。

未来独立域名部署应发布完整导出目录，调整入口 `base` 与站内锚点，不能只复制一份HTML。当前无需域名或额外服务器配置。
