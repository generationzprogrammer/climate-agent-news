# 京津冀目标追踪与政策分类

## 目标追踪

入口：气候治理 → 京津冀绿色转型 → Target Tracker。可按地区、领域、目标年份检索，展开“口径与条款”核对原文和统计范围。

现有39项区域目标来自北京市、天津市碳达峰实施方案，以及河北省生态环境厅公开的省双碳实施意见解读。2026年10月10日由19项增加20项（增量105.3%），原19项ID与条款保留。新增内容包括绿色电力、清洁供暖、公共建筑改造、热泵、储能、负荷响应、新能源汽车、绿色出行及垃圾资源化。目标文件可早于现有滚动政策库的采集窗口；目标记录独立维护，不删改政策档案。河北来源属于主管部门公开解读，页面明确注明，不冒充已取得的原始公文全文。

`config/bth_targets.json`分别保存sources、targets、observations。每项目标保留地区、指标、领域、公布日期、目标年份、基期、数值、单位、比较方向、表述强度、统计范围、原文摘句及条款位置。同一数值在不同年份作为不同目标记录保留；新增目标或修订须有官方出处，不能静默替换旧版本。

实绩比较要求地区、指标、单位、基期、scope同时一致。新能源装机不是发电量；可再生电力消纳占比不是可再生能源消费比重；非化石能源还包括核能。首次纳入的北京2025年18%可再生能源消费占比，来自市发展改革委2026年1月5日发布会，原文为“初步测算”，因此仅标为初步达到2025年14.4%目标，不作最终考核结论。2030年25%左右的目标使用同一观测显示进展，不标记已达标，也不为“左右”任意设置容差。其他未取得可比实绩的项目显示待核验；到期并不自动表示未达标。不生成完成率或自创绩效评分。

每日导出重建`bth_target_tracker.json`并将核验过的目标摘句、独立观测加入问答证据包。目标以kind=target保存，图表只接受kind=observation，不把目标值画成已实现数值。generated_at为导出日期，reviewed_at为条款核验日期；自动导出不意味着每天重新核验或自动发现所有修订。维护时补充新的官方实绩、目标修订和来源，再运行同一导出流程。

## 政策分类

参考北大宏观与绿色金融实验室[CCPID](https://github.com/MGFPKU/CCPID)及其[公开schema](https://github.com/MGFPKU/CCPID/blob/main/rules/schema.yaml)。政策工具机制分为经济工具、规制工具、政府投资与消费、信息工具、自愿措施；配置中下设适用于地方检索的组别。主题、地域、年份、文件类型为独立维度。

CCPID的工具单位与本站的文件单位不同。一份文件可以涉及多个工具；本站的文件数量不能解释为独立工具数量或政策成效。现有档案以题名元数据为主，故工具标签只对题名明确命中的关键词作预分类，保存命中词及title_keyword依据，未命中保留未分类。“方案”“通知”等一般文件名称不据此推断为规制工具。完整条款编码须另行阅读全文和核验。原始档案不写回分类结果，只有公开派生副本附加标签。
