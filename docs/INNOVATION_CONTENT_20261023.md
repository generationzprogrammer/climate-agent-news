# 科产融合案例内容整理

## 变更范围

- 全部案例和原始事实保持不变，显示层通过`casePresentation`生成事实卡和正文，不改变原JSON。
- 官方名录共通的机制折叠为“计划共同规则”；通用约束和转移提示不再逐条显示。具体高校实践保留。
- 机构名录未列名成员表示缺少公开列表，不显示“零成员”；不补造绩效。
- 直接显示已有高校、成员、合作方、技术专长、年份及所在地；原文技术任务可以展开，证据列表包含原文定位。
- CSV的`mechanism`仅保留案例描述；共同规则在`programme_rules`，`mechanism_scope`标识其层级。原始JSON仍可供研究追溯，旧快照不改。
- 6个能源相关中心追加专属官方详情、双语技术摘要、中文标题和12项带定位的技术任务或设施事实。`case_detail`为增量字段，旧字段、引用和案例数量保留；自动导出复用该层。设施能力不解释为实测性能提升，研究范围不解释为已实现成果。

## 数据质量基线

2026-10-23检查发布仓库标记2026-10-19的快照：1213条、541个机构或平台、672个项目；标识重复0。444条名录记录共用通用约束和借鉴文字，434条机制描述位于精确重复组。精确摘要重复0不能证明语义内容充分。

`scripts/audit_innovation_substance.py`记录字段重复、来源条数、起始时间缺失、观察层级和SHA-256。检查结果不作为“案例无效率”，也不替代独立内容审阅。Word报告提出后续补采合同、治理、技术验证及成果证据的具体字段和指标。

## 可持续性和限制

显示及CSV适配按记录类型执行，自动适用于日后同类新增案例，不增加请求或模型费用。六例补充使用官方正文进行编辑核对，不冒称独立双人验证。现阶段没有批量补写未核实的个体成效，也未建立新的相似案例算法或国家绩效评分。目录记录仍需后续深描。

## 验证

`node --test tests/innovation-cases.test.cjs tests/innovation-substance.test.cjs`；桌面与手机运行`node scripts/qa_innovation_research.cjs`。新增测试检查原数据不变、共同规则分离、未知不作零、个体实践和原文保留、CSV层级分离。
