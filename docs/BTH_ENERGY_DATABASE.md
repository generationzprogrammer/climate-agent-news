# 京津冀能源统计数据库与碳中和进程监视器

## 数据与展示

旧的京津冀专题入口及锚点保留，名称改为“京津冀能源统计数据库”。原始1214条统计记录、政策档案与原19项目标均不删除。统计检索支持地区、年份、分类维度及指标、变量、来源、编号文本搜索；每条保留原始单位、来源、定位、口径、取得日，核实后另记公布日。

六个分类维度：能源供需、清洁能源与结构、产业活动、交通与建筑、经济社会、资源与环境。经济社会重点包括常住人口、现价GDP、产业增加值及居民生活用电。未取得的就业、收入或碳排放数据不以其他指标冒充。

监视器直接使用`bth_energy_database.json`中的记录ID，“查看记录”定位到同一条统计记录，而非独立录入第二套数字。最新实绩逐地区标明所属期；年度历史采用原生横向条形图比较，不在2015、2020、2025几个锚点之间插值。月度累计另列，不拼接到年度趋势。未来栏显示政策目标及官方依据，不当作预测。初步测算明确标注，不计算自创碳中和完成率。可再生能源消费比重、可再生电力消纳比重、本地可再生发电占比互不替代。

## 每周自动更新

`.github/workflows/bth-energy.yml`每周一北京时间07:10执行，GitHub排队可能延后，无需本地电脑运行。每来源最多4个发布页，遵守robots和访问限制，遇401、403、429停止该域名；不调用模型或收费数据接口。2026年10月10日的联网试跑核查三个地区，已识别北京2026年1—8月新能源汽车累计产量41.7万辆，原数据保留。不同地区发布频率不同，不能保证每周都有新数值。

原始数据在`config/bth_energy_evidence.json`；自动增量独立保存于`data/bth_energy_updates.json`。严格指标名称与单位规则用于可支持的年度公报及月度累计系列；已发现发布不等于所有数字已可自动抽取。未支持的图表和文件不猜测数值。相同期间同口径同值不重复入库，冲突值进入`review_queue`，不覆盖原值。监视器显示最后成功核查日，各来源失败时保留旧值；最后尝试、最后成功核查、最后数值变更分别保存。

更新提交后显式触发Pages重建（GitHub自动令牌的push本身不会触发后续push工作流），确保已保存的增量进入网站与研究问答证据包。每日新闻自动更新机制不变。

## 质量验证与图表约定

数据库记录粒度为地区、指标、所属期、单位和来源。目标的比较要求地区、指标、单位、基期和统计范围全部匹配。保留不同版本GDP的原始口径说明，不以现价数值计算实际经济增长。公布日缺失显示“未核定”，不从URL或取得日猜测。

图表问题为“同一指标在不同地区及已观测年份的数值差异”。采用网站已有条形图组件，数量轴从零开始，直接显示原值和单位，地区与年份直接标注；只有2—3个年份时不绘制连续趋势。支持原始记录跳转，桌面与手机均验证布局。图表不用于推断政策因果效果或比较不同指标的完成率。

`tests/test_bth_energy.py`检验旧ID保留、来源、时间粒度、缺值、非有限数、目标隔离、增量冲突与严格比较方向。`scripts/check_bth_monitor_browser.cjs`以独立桌面和手机访客环境验证检索、历史比较、目标、记录跳转、无验证问答及订阅主端点失败后的备用提交通道；全部使用模拟问答和邮箱，不调用付费模型、不写入真实订阅。

## 设计参考

- 北京大学宏观与绿色金融实验室[政策工具数据库](https://mgflab.nsd.pku.edu.cn/en/DATABASE/POLICYTOOLDATABASE2/index.htm)：政策、目标和工具分层，不将文件计数解释为政策成效。
- [中国环境监测总站](https://www.cnemc.cn/)：按地区、数据所属期和指标呈现监测结果。本项目主要为官方年度及月度统计，不声称具备实时温室气体监测能力。
