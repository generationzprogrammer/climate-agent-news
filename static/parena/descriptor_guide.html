The KPI64 descriptor set

64 numerical molecular descriptors, in the exact order used by PARENA. Structure-based features are deterministic and do not use target values. The source implementation is supplied in parena/chemistry.py.

Atomic lookup descriptors support H, C, N, O, F, Si, P, S, Cl, Br and I. Verify applicability for metal-containing or unusual molecules. The compatibility implementation replaces undefined descriptor values with zero; descriptor reliability should be checked for such structures. Molecular identity grouping is conservative across stereochemistry and tautomers.
