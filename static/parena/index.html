First time here? Set up the local service
  1. Download the local workspace and extract it.
  2. Install Python 3.10–3.12. Run python -m pip install -e "package[web,molecule]" inside the extracted folder.
  3. Run python web/server.py or double-click start_local.cmd.
  4. Open the link printed in that terminal. Keep the terminal open during analysis.

If your browser blocks access to the local service, open the local page. You may need to allow the browser’s local-network permission.

01 / Numeric features

Include numeric predictors and one target column. Text predictors need explicit encoding. Provide a group column for repeated molecules, formulations or experiments.

Example Excel ↓
02 / Molecular input

Include a valid SMILES column and a target. KPI64 is computed locally with RDKit. Matching molecular identities stay together in the split.

Read all 64 descriptor definitions ↗
03 / Data requirements

At least 30 labeled rows and 8 independent groups. Classification: 2–10 classes and at least 5 groups per class. CPU interface: up to 2,000 rows and 128 numeric features.

04 / Reproduce the analysis

The result bundle contains predictions, split assignments, model-selection records, SHAP values, pair provenance, figure data, settings and the PDF report.
